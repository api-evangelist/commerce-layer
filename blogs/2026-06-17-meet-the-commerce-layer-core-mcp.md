Introduces the Commerce Layer Core MCP server, which gives AI agents secure, schema-aware access to the platform's commerce infrastructure. The server lets agents discover the resources schema and validate calls before making them, so they can interact with orders, customers, inventory, and pricing safely without custom connectors or simplified toolsets.
